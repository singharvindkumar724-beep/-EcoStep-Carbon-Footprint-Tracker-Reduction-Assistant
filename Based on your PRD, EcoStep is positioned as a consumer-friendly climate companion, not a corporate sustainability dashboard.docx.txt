Based on your PRD, EcoStep is positioned as a consumer-friendly climate companion, not a corporate sustainability dashboard. The UI should feel optimistic, intelligent, and motivating rather than technical or guilt-driven. The PRD repeatedly emphasizes approachable, motivating, and genuinely useful while maintaining accessibility and mobile-first usability.

Purpose
Generate personalized climate recommendations.
Endpoint
POST
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-pro:generateContent

{
  "userProfile": {
    "diet": "omnivore",
    "transport": "car",
    "household": 2
  },
  "footprint": {
    "annualCo2": 4800
  }
}

  "recommendations": [
    {
      "title": "Reduce Meat Consumption",
      "savings": 420,

}
